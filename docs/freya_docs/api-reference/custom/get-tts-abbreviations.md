# Get TTS abbreviations

> Returns the current TTS abbreviations list (`textSubstitutions`) for an agent
or workflow. Identify the target by either `id` (UUID, preferred) or `name`.
The resolver checks agents first, then workflows. If `name` matches multiple
rows in either table, or matches both an agent and a workflow, the request
fails with 409 — pass `id` to disambiguate.
